# 🚀 LinkedIn Post Automation using n8n

## 📌 About the Project

This project automates LinkedIn post publishing using **n8n**, a workflow automation platform. It helps reduce manual work by connecting workflow automation with LinkedIn to publish posts efficiently.

## 🎯 Objectives

- Automate LinkedIn post creation and publishing.
- Reduce repetitive manual work.
- Schedule posts for regular content sharing.
- Explore AI-powered content generation and workflow automation.

## 🛠️ Technologies Used

- **n8n** – Workflow automation
- **LinkedIn** – Professional content publishing
- **AI / Generative AI** – Content generation, if configured
- **Schedule Trigger** – Automated execution at a scheduled time

## ⚙️ Workflow

1. **Schedule Trigger** – Starts the workflow at the configured time.
2. **AI Agent** – Generates post content, if included in the workflow.
3. **LinkedIn Node** – Publishes the generated or prepared content to LinkedIn.
4. **Automated Execution** – Runs according to the workflow schedule when the workflow is active and the required services are available.

## ✨ Features

- Automated LinkedIn post publishing
- Scheduled workflow execution
- Reduced manual effort
- AI-generated content support
- Repeatable workflow for consistent content sharing

## 🚀 How It Works

1. Create a workflow in n8n.
2. Configure the Schedule Trigger or another suitable trigger.
3. Add an AI Agent if you want to generate post content automatically.
4. Connect your LinkedIn account using the supported credentials.
5. Configure the LinkedIn publishing node.
6. Test the workflow.
7. Activate the workflow to enable scheduled execution.

## 🔐 Requirements

- An n8n instance (cloud or self-hosted)
- A LinkedIn account
- LinkedIn credentials and permissions supported by the chosen integration
- AI model credentials, if using AI-generated content
